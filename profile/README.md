## What every kit promises

- **No code needed.** Everything is reachable from the kit's own windows, with a tooltip on every control.
- **Safe for your project.** Never edits your packs' own files, one undo per action, no package dependencies.
- **Built for real production.** Every tool is used in a game in development and covered by automated tests.
- **Documented.** Full docs ship inside the package and are online at [romanoassets.github.io](https://romanoassets.github.io).
- **Supported.** Ask on [Discord](https://discord.gg/AmpBDxRAKu) or open an issue in [RomanoAssetSupport](https://github.com/romanoassets/RomanoAssetSupport/issues).
